# מסיבת האורחים — אוטומט תאי

סימולציה של מסיבה לפי הרעיון של A. K. Dewdney (Scientific American, ספטמבר 1987),
כאוטומט תאי סטנדרטי לקורס 20581, מטלה 01, שאלה 2.

חמישה אורחים ושולחן אוכל יושבים על לוח. כל אורח רוצה מרחקים מסוימים מן האחרים
ומן השולחן. האורחים קצרי רואי: כלל המעבר קורא רק את התא ואת שמונת שכניו.
מרחק מגיע אליהם כגל שמתקדם תא אחד בכל דור. אחרי שהגל חוצה את החדר, כל אורח
זז לכל היותר צעד אחד לתוך תא ריק, אם הצעד משפר את השורה שלו במטריצת ההעדפות.

הלחץ הגלובלי (סכום הסטיות מן המטריצה) מחושב רק במוניטור שב־`simulation.py`.
הכללים לא קוראים אותו.

## קבצים

| קובץ | תפקיד |
| --- | --- |
| `constants.py` | כל הקבועים של המודל |
| `ca_rules.py` | מצבים, שכנות, וכלל המעבר. בלי גרפיקה |
| `matrices.py` | מטריצת הדוגמה ומטריצה עם מרדף, בודד וחבורה |
| `simulation.py` | אתחול אקראי, הרצה, מדידת איכות, שמירת תוצרים |
| `viz.py` | כל הציור |
| `gui.py` | אנימציה בחלון |
| `test_ca.py` | בדיקות: סופיות השדה, מקומיות, יישוב קונפליקט, ירידת לחץ |
| `report.md` | הדוח בעברית |
| `report.pdf` | אותו דוח, מוכן להגשה |
| `output/` | ריצה של 2000 דורות, חמישה זרעים, שתי המטריצות |

## הרצה

```bash
python3 -m pip install -r requirements.txt
python3 -m unittest test_ca.py
python3 simulation.py
python3 gui.py --matrix interesting --seed 0
```

`simulation.py` בלי ארגומנטים מריץ את שתי המטריצות, זרעים 0–4, 2000 דורות,
וכותב מחדש את `output/`. אפשרויות:

```bash
python3 simulation.py --matrix example --seeds 0 1 --generations 400
python3 simulation.py --no-figures
python3 gui.py --matrix example --seed 1 --stride 3 --interval 30
```

בלי מסך, או בלי Tkinter, `gui.py` שומר gif במקום לפתוח חלון.

השולחן קבוע במרכז הלוח. מיקומי האורחים בדור 0 נקבעים לפי הזרע.
אותו זרע נותן אותה ריצה.
